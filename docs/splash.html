Worm screens

Ten little animations for the 128×64 screen on every bin. A board plays one of them when it powers on, a different one each time, before the school card and the readings. These are the real pixels: the same code that runs on the Pico was run on a desktop and every frame captured, so what you see here is what the screen does, three times bigger.

They live in lib/wormshow.py, each one a few dozen lines of circles, lines and text. Make your own: copy one, give it a name and a draw(o, t), add it to SHOWS. A board can run all of them in a loop as a demo (tools/splash_demo.py), and tools/gen-splash.py plus tools/splash-gif.py make these pictures.

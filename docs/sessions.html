The Sessions

The workshop is four steps, in order. Each one proves that a single new thing works before the next step builds on top of it. So when something goes wrong, you know it's the thing you just added, not a mystery.

1

Microcontrollers

Meet the Pico. Get code onto it, run it, and watch it keep running on nothing but wall power, with no computer attached.

Electronics & Breadboarding

Now wires between parts. Push a little screen onto a breadboard, connect four wires, and light it up with code you already know how to run.

Soldering

A few things that are true of every station

Once you get to sensors, they all behave the same friendly way. Learn it once.

Nothing breaks the lesson

A station runs fine even if a part is missing or a wire falls out. Plug the part back in and it picks up again in a couple of seconds. No restart, no panic.

The little light tells the truth

The green light on the Pico is honest. Blinking = your code is running. It even blinks a code for which part is unhappy:
. . . _ . means part 4 has a problem. Dark = nothing is running.

It makes its own WiFi

Each station creates a little WiFi network named after itself (like PicoLab530). Join it on your phone and browse to the address on the screen, no internet required.

One click loads everything

Every sensor has an "Install" link. With your Pico connected, one click puts all the code it needs onto the board. No copying files by hand.

The wiring is always the same few colors

Every diagram in this guide uses the same wire colors, so anyone can read anyone's breadboard.

Wire colorWhat it carries
RedPower (3.3 volts). The part's "VCC" or "VIN".
BlackGround. The shared zero. Every part connects back to it.
Blue (SDA)The I2C data line. Blue and yellow are the colors on every STEMMA QT / Qwiic cable, so plug-in parts match too.
Yellow (SCL)The I2C clock line. Many parts share this SDA + SCL pair. (The DS18B20 probe's yellow wire is its own data line, on its own pin.)
GreenA part's own signal wire, anything that isn't power, ground, data, or clock.

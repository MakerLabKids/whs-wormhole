A bin over Bluetooth

No Wi-Fi switch: the board advertises its own name. Connect, read the bin, and set its messages with the board's PIN. The same requests as the board's web page, one line each.

This browser has no Web Bluetooth. It works in Chrome or Edge on Android, Windows, macOS and Chromebooks, over https. On an iPhone use the board's Wi-Fi page instead, or the Bluefy app.
Use Chrome or Edge. Vivaldi, Brave and Opera have the API but no device chooser, so the request "cancels" the moment you allow it. No pairing is involved: the board never shows up as pairable in the system's Bluetooth settings, only in this page's chooser.
